Detailed Description

Individual motor controller with feedforward control.

Provides high-level control for a single motor using feedforward control based on motor constants. The controller can apply voltages, accelerations, and velocities while respecting physical constraints and deadbands. It also tracks motor data for system identification purposes.

Bounds desired velocity to achievable limits.

Limits a desired velocity to values that can be achieved within the given time step, accounting for maximum acceleration constraints and current motor velocity. Also applies deadband filtering to prevent small commands. This prevents the controller from requesting velocities that would require impossible accelerations.

Parameters
[in]desired_velocityTarget velocity in rad/s
[in]dtTime step in seconds for calculating velocity change limits
Returns
Bounded velocity that is achievable within the time step

◆ move_motor_voltage()

void MotorController::move_motor_voltage ( const double & voltage)

Applies a voltage directly to the motor.

Sets the motor voltage, clamping it to the maximum voltage limit defined in motor constants. The voltage is converted from volts to millivolts for the PROS motor API. This is a low-level control method that bypasses velocity and acceleration limiting.

Parameters
[in]voltageDesired voltage in volts (will be clamped to max_voltage)
