Detailed Description

template<typename T>
struct rollers< T >

Template structure for two-roller intake system.

Represents the front and back rollers of an intake system. Provides array-like access and iteration capabilities for uniform processing of both rollers.

Template Parameters
TType of data stored for each roller (e.g., MotorController, double, etc.)
