\doxysubsection{Detailed Description}
Intake system controller with color sorting capabilities. 

Manages a two-\/roller intake system with motor controllers and optional color-\/based sorting. The intake can operate in various states (off, intake, scoring at different heights) and can automatically sort game pieces by color when enabled.
