\hypertarget{md_README_autotoc_md1}{}\doxysection{\texorpdfstring{About This Repository}{About This Repository}}\label{md_README_autotoc_md1}
Welcome to the code repository for {\bfseries{Team 75551}}, featuring advanced robotics control systems for VEX Robotics Competition. This repository contains a comprehensive PROS-\/based control system implementing feedforward control, motion profiling, localization, and intelligent mechanism control.

This codebase represents a complete solution for competitive robotics, featuring\+:


\begin{DoxyItemize}
\item {\bfseries{Holonomic Drivetrain Control}} with six-\/wheel kinematics
\item {\bfseries{Feedforward Motor Control}} with system identification
\item {\bfseries{Motion Profiling}} for smooth autonomous movements
\item {\bfseries{Odometry-\/\+Based \doxylink{classLocalization}{Localization}}} for precise position tracking
\item {\bfseries{RAMSETE Path Following}} for accurate trajectory tracking
\item {\bfseries{Intelligent Intake System}} with color-\/based sorting
\end{DoxyItemize}

\hypertarget{md_README_autotoc_md3}{}\doxysection{\texorpdfstring{Features}{Features}}\label{md_README_autotoc_md3}
\hypertarget{md_README_autotoc_md4}{}\doxysubsection{\texorpdfstring{Current Implementations}{Current Implementations}}\label{md_README_autotoc_md4}

\begin{DoxyItemize}
\item {\bfseries{Feedforward Velocity Control}} ~\newline
 DC motor control using feedforward constants (K\+\_\+v, K\+\_\+a, K\+\_\+s) for precise velocity and acceleration control without requiring feedback loops.
\item {\bfseries{System Identification}} ~\newline
 Automated motor characterization that determines feedforward constants through steady-\/state and acceleration testing. Supports multiple motors simultaneously.
\item {\bfseries{Holonomic Drivetrain}} ~\newline
 Six-\/wheel holonomic drivetrain (4 mecanum + 2 omni wheels) with differential drive kinematics, velocity bounds calculation, and acceleration-\/limited control.
\item {\bfseries{Motion Profiling}} ~\newline
 Trapezoidal and triangular motion profiles for linear and angular movement with configurable acceleration and velocity limits.
\item {\bfseries{RAMSETE Controller}} ~\newline
 Nonlinear feedback controller for path following that provides stable convergence to desired poses and velocities, even with modeling errors.
\item {\bfseries{Odometry-\/\+Based \doxylink{classLocalization}{Localization}}} ~\newline
 Position tracking using rotation sensors and IMU, with support for pose reset and continuous pose updates.
\item {\bfseries{Intake System with Color Sorting}} ~\newline
 Two-\/roller intake system with automatic color detection and sorting based on alliance color. Supports multiple scoring heights with state-\/based control.
\item {\bfseries{Motor Controller Abstraction}} ~\newline
 High-\/level motor control with velocity bounds, deadband filtering, and acceleration limiting. Supports both voltage and acceleration-\/based control.
\item {\bfseries{\doxylink{classSimplex}{Simplex} Linear Programming Solver}} ~\newline
 Two-\/phase simplex method implementation for solving linear programming problems, useful for optimization tasks in robotics.
\end{DoxyItemize}
