\doxysubsection{Detailed Description}
\doxylink{classSimplex}{Simplex} method solver for linear programming problems. 

Implements the two-\/phase simplex method to solve linear programming problems of the form\+: maximize c\texorpdfstring{$^\wedge$}{\string^}T x, subject to A x \texorpdfstring{$<$}{<}= b, with x unrestricted. The solver handles unrestricted variables by splitting them into positive and negative parts, and uses artificial variables when needed for feasibility.

Solves a linear programming problem using the simplex method. 

Solves the LP problem\+: maximize c\texorpdfstring{$^\wedge$}{\string^}T x, subject to A x \texorpdfstring{$<$}{<}= b, where x is unrestricted (can be negative). The method uses a two-\/phase approach\+: Phase I finds a feasible solution using artificial variables, and Phase II optimizes the objective function. Unrestricted variables are handled by splitting each into positive and negative components (x = x\+\_\+pos -\/ x\+\_\+neg).

The algorithm converts constraints to standard form, adds slack/surplus variables, and iteratively pivots to find the optimal solution. Returns an empty optional if the problem is infeasible.
