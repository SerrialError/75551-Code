\doxysubsection{Detailed Description}
Main drivetrain class for holonomic robot control. 

This class manages a six-\/wheel holonomic drivetrain with motor controllers, localization, and motion profiling capabilities. It provides methods for controlling the robot\textquotesingle{}s movement using differential drive kinematics, field-\/oriented control, and various motion profiles including Ramsete path following.
