\doxysubsection{Detailed Description}
System identification for motor characterization. 

Performs system identification to determine feedforward constants (K\+\_\+v, K\+\_\+a, K\+\_\+s) for DC motors. The identification process involves applying known voltages, measuring steady-\/state velocities and accelerations, and fitting the data to the motor model. This is typically done once per motor to calibrate control.
